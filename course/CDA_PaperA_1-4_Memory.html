Aim and objectives

Aim. To prepare you to explain the processes, neural basis, types, distortions and disorders of memory for MRCPsych Paper A.

At the end of this chapter, you should be able to:

  1. Describe encoding, storage, consolidation and retrieval, and explain reconsolidation after recall.
  2. Explain the role of the hippocampus, using patient HM, and describe long-term potentiation via NMDA receptors.
  3. Compare Atkinson and Shiffrin's multi-store model with Baddeley and Hitch's four-component working memory model.
  4. Classify long-term memory into declarative (episodic, semantic) and non-declarative (procedural, priming) types, following Tulving and Squire.
  5. Explain forgetting and distortion using Ebbinghaus's forgetting curve, interference, Bartlett's reconstruction and Loftus's misinformation effect.
  6. Distinguish anterograde from retrograde amnesia, apply Ribot's law, and outline the order of bedside memory testing.
  7. Answer the chapter's 98 exam-style questions, scoring at least 80%, by the end of this chapter.
