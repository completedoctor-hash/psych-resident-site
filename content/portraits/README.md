# Portraits

Drop a photograph in here and the timeline uses it automatically. Leave it empty and
you get a lettered medallion instead, which looks deliberate rather than broken.

## Naming

Lowercase, hyphens instead of spaces, `.jpg`. The file name is the person's name.

    john-cade.jpg
    emil-kraepelin.jpg
    alois-alzheimer.jpg
    philippe-pinel.jpg
    eugen-bleuler.jpg
    sigmund-freud.jpg
    erving-goffman.jpg
    aaron-beck.jpg

Square images work best. Anything from about 300 by 300 pixels upward is fine.
Nothing else needs changing. If a file is missing the page falls back to the medallion.

## Where to get them, legally

Almost every figure before about 1930 died long enough ago that their portraits are
public domain. **Wikimedia Commons** is the right source, because every file states
its licence on the page.

1. Go to commons.wikimedia.org and search the name.
2. Open the image and read the licence box. Look for **Public domain** or **CC BY-SA**.
3. Download, crop square, rename as above, drop it in this folder.

If a file is CC BY-SA rather than public domain, the licence requires you to credit the
author. Add a line to the site's credits page when you add such an image.

## Who is still in copyright

Anyone photographed recently. Aaron Beck, Marsha Linehan, John Kane, Michael Rutter and
other living or recently deceased figures will usually have copyrighted portraits.
Do not lift those from a search engine. Either leave the medallion, or ask permission.

A lettered medallion is a perfectly respectable design choice. An unlicensed photograph
on a commercial site is a bill waiting to arrive.
